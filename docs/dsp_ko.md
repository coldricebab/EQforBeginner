# DSP 명세

구현된 알고리즘 식별자:

- `phase1-bounded-boost-v2`: 공간적으로 게이트된 부스트를 +3 dB로 제한하는
  결정론적 오프라인 크기 보정.
- `phase3-single-sub-ranking-v2`: 실측된 수동 단일 서브우퍼 설정의 결정론적
  순위 산정.
- `phase3-separated-path-delay-polarity-search-v5`: 물리적으로 측정된 크로스오버
  상태 전반에 걸친 메인 지연과 0/180도 극성 대안의 유계 복소 합성. 각 후보의
  서브를 메인에 레벨 매칭한(보고되는 배포 트림) 상태로 채점한다.
- `phase3-wide-band-crossover-synthesis-v1`: 광대역 서브 캡처 1회와 풀레인지 메인
  캡처로부터 선언된 LR4/LR2/BW2 슬로프 모델로 가상 크로스오버 상태를 합성. 측정
  상태의 로우패스는 겹쳐 쌓지 않고 치환하며, 같은 지연/극성 최적화기에 공급한다.
- `phase4-response-replay-v2`: 측정된 결합 응답 기준선으로부터의 결정론적 48 kHz
  minimum-phase 설계와 예측 전용 검증.
- `phase6-native-six-rate-v2`: 여섯 개 타깃 레이트 전부에서의 독립적인 네이티브
  그리드 합성, 공통 안전 정규화, 레이트 간 크기/군지연 검사.
- `wireless-sweep-recognition-v1`: 비동기 마이크 캡처에 대한 기지 WAV 인식.
  이것은 파일/오프셋 증거이며, 절대 채널 타이밍이 아니다.
- `umik-calibration-parser-v2`: 엄격한 UMIK 형식 TXT 파싱, 따옴표로 감싼 miniDSP
  메타데이터 호환성, 로그 주파수/선형 dB 크기 보정 보간.
- `known-sweep-deconvolution-v5`: 인식된 캡처의 리샘플링, 마커 기준 경로에 대한
  고정 부호 있는 pre-zero 유지, 정규화된 기지 스윕 디컨볼루션, 크기 캘리브레이션,
  측정 품질 게이트. 65,536포인트/0.73 Hz 분석 그리드에서 32,768 샘플(0.68 s)을
  유지하므로 좁은 저주파 모드가 측정된 피크 레벨을 그대로 보존하며, 부호 있는
  pre-zero 창은 4,800 샘플(100 ms)이므로 음향 마커 기준보다 먼저 도착하는 경로가
  샘플 0에서 잘리지 않고 온전히 유지된다. 유지되는 꼬리는 번들 스윕의 깨끗한
  end 마커 이전 간격 안에 머무르고, 노이즈 플로어 추정은 가드 직전 4,800 샘플로
  제한되어 프리롤을 따라 start 마커의 잔향으로 들어가지 못하며, v3 이하의 캐시는
  더 세밀한 그리드와 혼용되지 않고 복원 시 거부된다.
- `uploaded-wav-marker-channel-analysis-v1`: main/start/end 구간 분리와 마커별
  L/R 재생 채널 분류.
- `known-marker-capture-endpoint-v4`: 음향적으로 완화된 start/end 마커 인식,
  불균등한 반복 후보 유지, 단일 마커 타이밍 적합이 룸 편향된 5개 전체 세그먼트
  후보의 제한적 허용, 엄격한 쌍 간격 검증, 유계 실시간 진행 모니터링, 인식 이전
  입력 활동, 고정된 마커 이후 지연 없이 완전한 end 마커에서의 완료.
- `umik-sweep-level-assessment-v2`: 선호 및 강제 메인 스윕 디지털 피크/RMS 경계와
  선택적이며 명시적으로 가정된 Sens-Factor SPL 추정.
- `secs-port-v1`: 한플님의 SECS 전대역 단일 지점 혼합위상 보정 이식(MIT 허가).
  2.1에서는 확정된 크로스오버 아래를 좌우 공통으로 보정한다. 기본 켜짐인 "개량
  SECS" 옵션에서는 라벨에 `+phase-guard-v1`이 붙는다: 실현 불가능한 위상 보정을
  무보정으로 되돌리고 설계된 필터가 군지연 게이트를 통과해야 한다.
- `live-closed-loop-validation-v4`: 시험 이후 P0 주파수 응답 및 예측 대비 검증된
  결과의 허용 게이트.
- `verified-trial-native48-response-binding-v1`: 최종 네이티브 48 kHz 응답을
  물리적으로 재측정된 바로 그 시험에 결속.
- `validation-signal-and-response-peak-v3`: 4배 오버샘플링된 등록 스윕 입출력 피크
  비율과 FIR L1 최악 케이스 샘플 피크 한계.

별도 표기가 없는 한 기호는 dB 단위의 레벨이다. Phase 3은 제공된 측정만 순위화한다.
측정되지 않은 하드웨어 설정을 합성하지 않으며, 앰프나 서브우퍼를 변경했다고
주장하지 않는다.

## 주파수 응답

임펄스 응답 `x[n]`에 대해 네이티브 단측 응답은 다음과 같다.

```text
X[k] = FFT_N{x[n]}
L[k] = 20 log10(max(|X[k]|, 1e-15))
f[k] = k Fs / N,  k = 0..N/2
```

`N`보다 짧은 입력 IR은 0으로 패딩된다. Phase 1은 선언된 합성 타임라인을 사용한다.
실제 도착 시간 추정은 유보되어 있으며, 최대 샘플을 0으로 옮기는 방식으로 결코
대체되지 않는다.

Phase 4 REW 리플레이에서는 저장된 룸 IR로부터 설계 크기를 재구성하는 데 이 FFT
식을 사용하지 않는다. 단순 IR FFT는 REW의 창 처리와 캘리브레이션 의미를 재현하지
못하므로, REW가 저장한 캘리브레이션된 크기 샘플이 권위 있는 주파수 응답 입력이다.
별도로 유지되는 원시 IR은 아래에 정의된 타임라인 보존 컨볼루션 진단에만 사용된다.

## 비동기 무선 경로에서의 기지 WAV 인식

`r[n]`을 디코딩된 모노 레퍼런스, `x[n]`을 변형되지 않은 마이크 캡처라 하자. 전역
탐색은 레퍼런스 중간의 특징적인 프로브 `p[n]`을 취해 프로브와 같은 길이의 각 캡처
창에서 평균을 제거한 뒤 다음을 평가한다.

```text
rho[l] =
  sum_n (p[n]-mean(p)) (x[l+n]-mean(x_l))
  ------------------------------------------------
  sqrt(sum_n (p[n]-mean(p))^2 sum_n (x[l+n]-mean(x_l))^2)
```

구현은 캡처 창의 평균과 에너지를 직접 갱신하면서 유계 오버랩/블록 FFT로 분자를
계산한다. 설정된 최대 레이트 불일치 하에서 거의 완전한 레퍼런스를 담을 수 있는
지연만 탐색한다. 인식에는 절대 상관을 사용하므로 반전된 음향 극성이 계속 검출
가능하며, 조용히 보정되지 않고 보고된다.

상관 피크 하나만으로는 충분하지 않다. 레퍼런스 가장자리에서 떨어져 분포한 일곱
개의 세그먼트를 유계 국소 창 안에서 정합한다. 채택된 쌍 `(r_j, c_j)`은 다음에
적합된다.

```text
c_j = a + b r_j + epsilon_j
drift_ppm = (b - 1) * 10^6
fit_rms_samples = sqrt(mean_j(epsilon_j^2))
```

`a`는 캡처 기준의 재생/음향 오프셋이고 `b`는 실효 캡처/레퍼런스 샘플 비율이다.
추론된 파일 끝은 `a + b N_reference`이며, 시작과 끝 모두 원본 캡처 안에 남아 있어야
한다. 첫 피크에 근접하면서 충분히 분리된 두 번째 완전 후보가 존재하면 모호로
반환된다. 이 알고리즘은 IR 최댓값을 0으로 이동시키지 않는다.

단일 로그 스윕의 경우 `b`는 명시적으로 `intra_sweep_segment_fit`로 태깅된다. 세그먼트
주파수 변화와 룸 군지연이 이를 편향시킬 수 있기 때문이다. 이는 심각한 불일치의
기각과 향후 리샘플링 후보로는 적합하지만, 채널 간 클럭이나 도착 타이밍의 증거는
아니다. 반복된 동등 마커 또는 반복된 동일 여기만이 더 강한 타이밍 워크플로의 자격을
부여할 수 있다.

업로드된 스테레오 WAV와 마커 구간 `I`에 대해 채널 에너지는 다음과 같다.

```text
E_L = sum_(n in I) L[n]^2
E_R = sum_(n in I) R[n]^2
D_marker = 10 log10(max(E_L,E_R) / max(min(E_L,E_R), 1e-30))
```

정규화된 L/R 상관이 0.999 이상이고 레벨 차이가 1 dB 이하이면 동일 스테레오로
분류한다. 그렇지 않으면 에너지가 큰 쪽을 마커 재생 채널로 보고하고 그 파형이 인식
템플릿이 된다. 측정 스윕이 다른 채널을 점유할 수 있으므로 start와 end는 독립적으로
분류된다.

실시간 엔드포인트 모니터는 유계 중첩 캡처 스냅샷에서 첫 기지 마커를 탐색한다.
발견되면 그 소스 좌표가 측정 구간을 예측하고, 모니터는 그 구간에서만 피크와 RMS를
누적한다. 이어서 예측 좌표 근처에서 마지막 마커를 탐색한다. 짧은 마커의 내부
기울기는 룸 군지연에 의해 편향될 수 있으므로, 후보 생성은 내부적으로 25,000 ppm을
허용하고 최강 피크의 절반까지 두 번째 피크를 유지한다. 두 값 모두 클럭 증거로
채택되지 않는다. 시간순 start/end 쌍 간격만 5,000 ppm으로 검사한다. 완전한 마지막
마커가 인식되면 별도의 고정 꼬리 없이 해당 모니터 폴링에서 캡처를 종료한다. 가져온
WAV는 32,768 샘플 디컨볼루션 꼬리를 위해 end 마커를 메인 스윕 이후 충분히 뒤에 이미
배치해 두어야 한다. 최종 디컨볼루션은 fail-closed를 유지한다. 취소는 여전히 별개의,
기각된 종료 상태이다.

캘리브레이션 Sens Factor `S`에 대해 개발자 베타 표시는 다음을 추정한다.

```text
L_SPL_est = 94 dB + 24 dB - S + L_RMS,dBFS
```

24 dB 항은 알려진 UMIK 최대 입력 볼륨 관례를 명시된 운영체제 입력 게인 가정
0 dB로 변환한다. 이 추정은 참고용이다. 메인 스윕 피크는 -30 ~ -6 dBFS 사이여야 하고
기존 클리핑/SNR 게이트를 통과해야 한다. 결과를 인증된 절대 SPL로 취급하려면 물리적
SPL 캘리브레이터 또는 독립적으로 검증된 호스트 게인 매핑이 필요하다.

## 인식된 스윕 측정 추출

일반 측정 함수는 원본 캡처 세그먼트를 유지하고, 인식된 시작 `a`와 제공된 기울기
`b`를 사용해 레퍼런스 그리드 위에서 샘플링한다. 실시간 어댑터는 먼저 두 가지 증거
유형을 구분한다. 소스 좌표 `s_0,s_1`과 캡처 좌표 `c_0,c_1`에서 전후 타이밍 마커가
인식되었다면,

```text
b_marker = (c_1 - c_0) / (s_1 - s_0)
a_marker = c_0 - b_marker s_0
```

가 디컨볼루션 클럭 매핑에 사용된다. 두 동등 마커를 모두 확보하지 못하면, 어댑터는
인식기의 룸 편향된 스윕 내부 기울기를 진단용으로만 유지하고 `b=1`을 전달한다. 자격
미달 증거로 주파수 응답을 왜곡하지 않는다.

요청된 `M` 샘플 IR에 대해 정렬된 캡처는 `N_reference + M - 1` 샘플을 포함한다. 마커
기준 실시간 캡처는 48 kHz에서 고정 `P=4800` pre-zero 샘플을 사용하므로, 유지되는
IR 인덱스 `n`의 선언 시간은 다음과 같다.

```text
t_IR[n] = (n - P) / Fs
```

그리고 정렬된 캡처는 마커로 매핑된 메인 스윕 경계보다 `P/Fs = 100 ms` 앞에서
시작한다. 폴백 전체 스윕 인식은 `P=0`을 사용한다. 이는 피크 정렬이 아니라 고정된
좌표 선택이다. 최대 IR 샘플을 탐색하거나 이동시키는 일은 결코 없다. 이를 통해
측정된 좌측 메인 또는 서브 경로가 고정된 우측 마커 스피커보다 먼저 도착하더라도
샘플 0에서 잘리지 않는다. 다음 2의 거듭제곱 FFT 그리드에서,

```text
lambda = max_k |R[k]|^2 10^(regularization_db / 10)
H_raw[k] = Y[k] conj(R[k]) / (|R[k]|^2 + lambda)
```

기본 정규화는 -100 dB이다. 가져온 캘리브레이션이 요구 대역 20 Hz-20 kHz 전체를
포괄하면, 로그 주파수 보간된 가산 보정 `C(f)`가 다음과 같이 적용된다.

```text
H_cal[k] = H_raw[k] 10^(C(f_k) / 20)
```

선택적 위상 열은 유지되지만 적용되지 않는다. 감도는 IR/FR을 변경하지 않는다. 위에서
설명한 명시적으로 가정된 SPL 표시에만 사용된다. 원시 IR과 크기 캘리브레이션된 IR은
모두 유지된다. 기존 주파수 응답 분석기는 캘리브레이션된 IR을 평가하고, 기존 FFT
컨볼버는 원시 IR로부터 캡처를 재구성한다. 그 결과로 얻는 적합도는 코히어런스 추정이
아니다. 늦은 룸 감쇠, 스피커 고조파 왜곡, 유한한 IR 창은 REW 방식의 스윕 복원이
사용 가능한 경우에도 적합도를 낮출 수 있다. 따라서 완전한 반복 마커 쌍이 있으면
적합도는 진단 전용이 된다. 마커 간격이 독립적으로 범위와 클럭 비율을 확립하기
때문이다. 캘리브레이션, 클리핑, SNR, 레벨, 스트림 무결성은 강제 게이트로 남는다.
마커 없는 폴백은 그러한 독립 증거가 없으므로 여전히 12 dB 적합도를 요구한다. 다른
실시간 기본 임계값은 SNR 20 dB, 전체 스윕 상관 0.45 또는 반복 엔드포인트 마커별
0.20, 최대 레이트 불일치 2,000 ppm, 크기 전용 세그먼트 적합 최대 96 샘플(일반 코어
기본값은 24 샘플)이다. 단일 비동기 재생은 항상
`absolute_timing_eligible = false`를 보고한다.

캘리브레이션 파서는 공백/쉼표 구분자와 `#`/`;` 주석을 사용하는
`frequency_hz correction_db [phase_degrees]`를 받는다. 주파수는 반드시 순증가해야
한다. 일반적인 `Sens Factor` 또는 `Sensitivity` 헤더와 시리얼 번호는 유지된다. V1은
20 Hz-20 kHz 커버리지를 요구하고 로그 주파수 축에서 dB 단위로 보정을 보간한다.
선택적 위상 열은 의도적으로 적용하지 않으며, Sens Factor는 IR/FR을 변경하지 않는다.

## 다중 측정 위치 통계

P0는 가중치 2, P1-P5는 가중치 1이다. 선형 에너지 `E_i = 10^(L_i/10)`에 대해,

```text
L_energy(f) = 10 log10( sum_i w_i E_i(f) / sum_i w_i )
```

구현은 정규화된 가중치와 log-sum-exp 형태로 이를 평가하므로, 매우 큰 유한 가중치도
합에서 오버플로할 수 없다. 또한 dB 단위 가중 표준편차와 가중 분위수도 유지한다.
에너지 평균을 산술 dB 평균으로 대체하지 않는다.

## 타깃

번들 타깃은 공식 B&K 또는 Harman 데이터셋이 아니라 독립적인 `-style` 제품 커브이다.
버전 1은 노트 사이에서 `ln(f)` 축의 dB 선형 보간을 사용하고, 노트 범위 밖에서는
가장 가까운 끝점을 유지한다.

| Hz | B&K-style dB | Harman-style hi-fi dB |
| ---: | ---: | ---: |
| 20 | 6.0 | 7.0 |
| 30 | 5.3 | 6.6 |
| 50 | 4.2 | 5.6 |
| 80 | 3.2 | 4.4 |
| 120 | 2.4 | 3.3 |
| 200 | 1.4 | 2.0 |
| 500 | 0.0 | 0.0 |
| 1,000 | -0.5 | -0.4 |
| 2,000 | -1.0 | -0.9 |
| 5,000 | -2.2 | -2.0 |
| 10,000 | -4.0 | -3.8 |
| 20,000 | -6.0 | -6.5 |

설계 근거: 두 커브 모두 완만한 저역 셸프와 부드러운 전대역 하향 진단 경향을
제공한다. Harman-style v1이 베이스 셸프가 더 크다. 기본적으로 20-500 Hz만 완전히
보정되므로, 고주파 노트는 전대역 EQ에 대한 허용이 아니라 맥락 제공과 향후 대비를
위한 것이다.

사용자 타깃은 공백, 탭, 쉼표로 구분된 정확히 두 개의 숫자 열(`frequency_hz level_db`)을
받는다. 빈 줄과 `#`/`;` 주석은 무시된다. 주파수는 반드시 순증가해야 하고
`(0, 1,000,000]` 범위에서 유한해야 하며, 레벨은 `[-200, 200]` 범위에서 유한해야
한다. 오류에는 원본 줄과 유효한 예시가 포함된다.

실시간 마법사는 파싱된 `TargetCurve`를 프리셋이 사용하는 것과 동일한 Phase 4 설정에
그대로 전달한다. 원본 TXT, SHA-256, `target-txt-parser-v1`, 포인트/범위 메타데이터,
선택된 타깃 이름/버전, 200-500 Hz 정렬 대역을 실시간/최종 프로젝트 증거에 저장한다.
제공된 노트 범위 밖의 값은 가장 가까운 끝점을 사용하며, 파일이 20-500 Hz 보정 대역
전체를 포괄하지 않으면 UI가 경고한다.

타깃은 신뢰 가능한 200-500 Hz 기준 대역에서 `L_energy(f)-T(f)`의 중앙값을 사용해
수직 정렬된다. 기록된 오프셋은 모든 타깃 빈에 더해진다.

## 강건한 유계 게인 목적함수

각 주파수에서 측정 위치별 잔차와 가중 하위 분위수를 정의한다.

```text
r_i(f) = L_i(f) - T_aligned(f)
q(f)   = weighted_quantile_0.25({r_i}, {w_i})
e(f)   = L_energy(f) - T_aligned(f)
```

후보 컷은 `q(f) >= 0.75 dB`일 때만 존재한다. 즉 초과분이 하위 포락선 공간 테스트를
통과했다는 뜻이다. 스무딩 전 요청 감쇠는 다음과 같다.

```text
a_raw(f) = -clamp(max(0, 0.7 q(f) + 0.3 e(f)), 0, 12 dB)
```

컷 측은 12 dB 감쇠 한계와 하위 분위수 공간 정규화를 유지한다. 한 청취 위치에만
나타나는 피크는 하위 분위수 게이트를 통과할 수 없다.

양의 보정은 별개의 더 엄격한 경로이다. 측정 위치별 잔차를 1/3 옥타브 가우시안으로
스무딩하고 그 가중 상위 사분위수를 취한다.

```text
b_i(f) = smooth_1/3oct(r_i(f))
u(f)   = weighted_quantile_0.75({b_i}, {w_i})
```

부스트 요청은 최소 두 개의 측정 위치가 유지되고, `u(f) <= -1 dB`이며, 그 조건이
최소 `0.25 octave` 동안 연속될 때만 존재한다. 상위 사분위수라는 것은 가중 측정
위치의 약 3/4이 여전히 타깃보다 아래여야 함을 뜻한다. 낮은 청취 위치 하나가 부스트를
승인할 수 없다. 최종 스무딩/윈도우 이전에는,

```text
b_raw(f) = clamp(-u(f), 0, 3 dB)
```

유지된 원시 측정 위치 중 하나라도 타깃보다 8 dB 이상 낮은 빈은 보호되며 부스트
경로에 진입할 수 없다. 강건 피크 게이트가 활성이면 컷이 우선한다. +3 dB 상한은
제품 상수이며, 사용자가 완화할 수 있는 목표치가 아니다.

`a_raw`는 로그 주파수 축에서 1/12 옥타브 FWHM 가우시안으로 스무딩된다. 유지된 측정
위치 중 하나라도 정렬된 타깃보다 8 dB 이상 낮으면 그 빈은 보호된 딥이다. 감쇠는 각
보호된 딥의 0.10 옥타브 이내에서 부드럽게 0으로 복귀한다. 보정 대역 윈도우는
20 Hz부터 500 Hz까지 1이고, 500에서 650 Hz까지 raised-cosine으로 0으로 복귀하며,
20 Hz 미만과 650 Hz 이상에서는 0이다.

윈도우가 1이라는 서술은 설계된 보정 형태를 기술한 것이다. FIR 실현 과정에서 빈 간
게인을 1 미만으로 유지하기 위해 보고되는 주파수 무관 감쇠 전용 안전 정규화가 한 번
추가될 수 있다. 현재 합성 예시는 약 -0.3035 dB를 적용한다. 이 균일한 안전 트림은
고주파 음색 보정이 아니다.

요청된 모든 설계 단계와 스테레오 블렌드 단계는 다음을 재확인한다.

```text
-12 dB <= a(f) <= +3 dB
```

그리고 NaN/Inf를 거부한다. 12 dB 제품 상한을 넘는 최댓값 설정은 거부된다. 제약 없는
요청이 선택된 한계를 초과하면 감쇠 한계 경고가 기록된다. Phase 1은 그 경고를
차단 사유로 취급한다. Phase 4는 아래에 별도로 보고되는 보수적 재설계를 통해서만
이를 해소할 수 있으며, 원래 요청과 경고는 프로젝트 기록에 남는다. +3 dB를 넘는
요청은 강제 상한으로 클리핑되고 `boost-limit-reached`로 기록된다. 이는 보호된 딥
게이트나 공간 폭 게이트를 결코 완화하지 않는다.

## 공유 저역 스테레오 규칙

`a_L`과 `a_R`을 독립적으로 설계된 유계 요청이라 하자. 100 Hz 미만에서 공통 요청은
양쪽 부호 모두에 대해 보수적이다.

```text
a_common(f) = max(a_L, a_R), if both are cuts
              min(a_L, a_R), if both are boosts
              0,             if their signs conflict
```

설정 가능한 경계 `f0=100 Hz`와 `f1=140 Hz` 사이에서는,

```text
u = clamp( ln(f/f0) / ln(f1/f0), 0, 1 )
s = u^2 (3 - 2u)
a'_c = a_common + s (a_c - a_common), c in {L,R}
```

이 식은 양쪽 경계에서 기울기가 0이다. 140 Hz 위에서는 각 채널이 자신의 독립 요청을
사용한다. 이 경계값들은 설정이며, 시스템 고유 상수가 아니다.

## 수동 단일 서브 후보 순위 산정

구현된 Phase 3 슬라이스는 각 후보 하드웨어 설정에 대해 동일하게 선언된 측정 위치에서
캡처한 L+sub 및 R+sub 결합 응답을 비교한다. 모든 후보는 동일한 측정 위치 ID, 양의
측정 위치 가중치, 채널, 정확히 일치하는 주파수 그리드를 가져야 한다. `theta`가 측정된
후보를, `fc_theta`가 그 선언 크로스오버를 식별한다고 하자. 공통 비교 대역은 다음과 같다.

```text
B = [0.5 min_theta(fc_theta), 2 max_theta(fc_theta)] intersect measured grid
```

현재 측정된 70/80/90 Hz 집합에서는 35-180 Hz(396 빈)이다. 공통 대역은 각 크로스오버가
서로 다른 채점 범위를 받는 것을 방지한다. 캡처된 크기 `L_theta,p,c(f)`는 log2 주파수
축에서 기본 1/3 옥타브 FWHM 가우시안으로 스무딩된다.

```text
S_theta,p,c(f) = smooth_1/3_oct(L_theta,p,c(f))
E_p,c(f)       = max_theta S_theta,p,c(f)
d_theta,p,c(f) = max(0, E_p,c(f) - S_theta,p,c(f))
```

따라서 크기 항은 각 측정 위치, 채널, 주파수에서 실제로 측정된 최선의 응답 대비
후보의 결손을 측정한다. 이는 상대적인 후보 비교 목적함수이며, 타깃 커브 RMSE가
아니고 딥을 부스트해도 된다는 허용도 아니다. 주파수 집계는 `ln(f)` 축에서 사다리꼴
형태의 구적 가중치를 사용하므로, 조밀한 선형 주파수 소스 그리드가 고주파 끝단에
과도한 가중치를 주지 않는다.

```text
w_f[0]   = (ln f[1] - ln f[0]) / 2
w_f[i]   = (ln f[i+1] - ln f[i-1]) / 2
w_f[end] = (ln f[end] - ln f[end-1]) / 2
```

유지된 측정 위치, 양쪽 채널, 주파수 전반에 걸쳐 채점기는 가중 결손 RMS `D_rms`,
가중 95 백분위수 `D_95`, 최댓값 `D_max`를 기록한다. 측정 위치 가중치는 집계에
적용되며, P0=2와 주변 위치=1이 제품 기본값이다. 측정 위치가 둘 이상이면 최악의
청취 위치별 결손 RMS `D_seat`와 청취 위치별 RMS의 가중 표준편차 `D_spread`도
기록한다.

모든 응답에 위상이 포함된 경우, 보존된 주파수 데이터에서 위상 언랩과 유한 차분
군지연을 계산한다. 군지연은 기본 1/2 옥타브 FWHM으로 스무딩되고, 그 가중 중앙값이
제거되며, 남은 가중 RMS가 ms 단위의 `G_phase`이다. 모든 응답에 동일 설정 반복 타이밍
증거가 있으면, 그 재현성 산포의 가중 RMS가 ms 단위의 `T_repeat`이다. 두 증거 부류 중
어느 하나라도 불완전하면 해당 항은 모든 후보에서 생략되고 경고가 기록된다. 누락된
값은 결코 신뢰도 0의 증거로 대체되지 않는다.

기본 `RankingConfig`에서는 점수가 낮을수록 좋다.

```text
score(theta) = D_rms + 0.20 D_95 + 0.05 D_max
             + [0.25 D_seat + 0.15 D_spread, only with multiple positions]
             + [0.10 G_phase, only with complete phase evidence]
             + [0.10 T_repeat, only with complete repeat timing evidence]
             + 0.02 |main_delay_ms| + 0.02 |sub_level_db|
```

괄호 안의 계수와 스무딩 폭은 버전 관리되는 설정 기본값이며, 보편적인 음향 상수가
아니다. 극성 자체에는 정규화 비용이 없다. 알 수 없는 지연, 레벨, 극성, 위상 트레이스,
타이밍 반복은 알 수 없음으로 보존된다. 채점기는 이를 추론하지 않는다. 동점은 후보 ID로
결정론적으로 해소되며, 모든 보고서는 `needs_confirmation=true`로 설정한다.

후보 레벨은 의도적으로 정렬하지 않는다. 진단 목적으로만, 각 후보의 200-500 Hz 가중
중앙 레벨을 측정 위치와 채널에 걸쳐 계산한다. 최댓값에서 최솟값을 뺀 후보 산포가
기본값 1.5 dB를 넘으면 경고가 발생한다. 이 앵커 검사는 응답 값이나 순위 산정 입력을
결코 변경하지 않는다.

### 실시간 분리 경로 지연 및 극성 탐색

`phase3-separated-path-delay-polarity-search-v5`는 위의 실측 후보 envelope
목적함수가 아니라 자체 레벨 중립 이음새 목적함수(아래)로 채점한다.
그 입력은 일반적인 메인/서브 측정 하나에 가정된 크로스오버 모델을 더한 것이 아니다.
선언된 모든 크로스오버 `x`에 대해 사용자가 하드웨어를 물리적으로 구성하고 복소 P0
응답 `M_x,L(f)`, `M_x,R(f)`, 모노 `U_x(f)`를 측정한다. 따라서 앰프의 실제 하이패스/
로우패스 동작이 이미 각 측정 상태에 포함되어 있다. 최소 2개, 최대 12개의 고유한
오름차순 크로스오버 상태가 필요하다.

`tau_0`와 `p_0`를 그 캡처 동안 활성이었던 메인 지연과 0/180도 극성이라 하자. 후보
메인 지연 `tau`와 극성 `p`에 대해 채널 `c`의 합성 결합 경로는 다음과 같다.

```text
M'_x,c(f; tau) = M_x,c(f) exp(-j 2 pi f (tau - tau_0) / 1000)
U'_x(f; p)     = U_x(f) exp(j pi I[p != p_0])
C_x,c(f)       = M'_x,c(f; tau) + U'_x(f; p)
```

유계 지연 범위는 -20에서 50 ms 안에 있어야 하고 0.01–5 ms 스텝을 사용해야 한다.
그리드는 전체 범위가 아니다. 각 크로스오버는 측정된 서브 도달 시점을 중심으로 한
반주기 창을 범위로 잘라내고 절대 스텝 배수로 스냅해 탐색한다. 창 하나는 최대
1,001개의 값을, 전체 탐색은 최대 10,000개의 후보를 담는다. 요청한 스텝이 이
한도에 비해 너무 미세하면(40 Hz 후보의 25 ms 창을 0.01 ms 스텝으로 채우면
2,501개가 필요하다) 탐색은 거부하는 대신 2단계로 실행한다. 1단계는 한도에 맞는
스텝의 최소 정수배로 모든 창을 스캔하고, 2단계는 각 크로스오버의 1단계 최적점
양쪽 성긴 스텝 하나 범위 안에서 요청한 전체 해상도로 다시 순위를 매긴다. 두
단계 모두 하드웨어 스텝 배수만 담고, 각 미세 창은 자신의 성긴 승자를 포함하며,
점수의 지연 축 변동 스케일(최고 평가 주파수의 약 한 주기, ≥ ~2 ms)이 여기서
선택되는 어떤 성긴 스텝보다 수백 배 크므로 성긴 스캔이 최적점의 분지를 건너뛸
수 없다. 한도가 직접 수용하는 설정은 v2와 동일한 단일 단계 그리드를 만든다. 합성은
`max(20 Hz, 0.4 min(x))`부터 500 Hz까지의 양의 빈을 유지하고, 채점은 공통
`[0.5 min(x), 2 max(x)]` 대역에서 이뤄진다.

지연 창은 모두 하나의 도달 추정이 중심을 잡는다. 추정은 최저 크로스오버 경로에서
20 Hz부터 그 크로스오버의 2배까지의 대역 제한 복소 상관으로 이뤄진다. 서브-메인
상대 오프셋은 크로스오버 다이얼이 아니라 드라이버와 배치의 속성이며, ±20 ms 스캔
안에서 앨리어스가 없는 것은 최저 경로의 상관뿐이다. `f`를 중심으로 한 대역의
상관은 약 `1/f` 간격으로 반복되므로 높은 크로스오버 경로의 자체 추정은 저음 한
주기만큼 어긋난 곳에 잠길 수 있다(실측에서 참 오프셋이 약 −1 ms인 데이터에
12~15 ms 추천으로 관측됨). 최저 후보가 55 Hz를 넘는 계획에는 앵커 자체가
모호하다는 경고가 붙는다.

창 탐색에 앞서 각 경로의 서브를 메인에 레벨 매칭한다(v4에서 추가). `|U_x|`를
스무딩해 크로스오버 인접 옥타브 `[x/2, x]`에서 취한 가중 중앙값을 메인 자신의
raw 200–500 Hz 앵커(양 채널 평균)에 맞추는 이동량이 후보별 트림 `g_x`이며 —
사용자가 그 크로스오버를 선택한 뒤 실제로 수행하는 캘리브레이션이다 — 도달
추정, 합성, 채점 전에 `U_x`에 적용된다(±24 dB로 클램프, 경고 동반). 트림은
자유 탐색 차원이 아니라 권장값의 일부로(순위 항목마다 보고되고 서브 레벨
자문이 승자의 값을 되풀이한다), 아래 목적함수를 끝까지 레벨 중립으로 만드는
장치다. 캡처된 서브의 순수 게인 변화는 `g_x`에서 정확히 상쇄되므로 순위는
캡처된 서브 레벨에 불변이다. 캡처 레벨로 채점하면 메인보다 ~10 dB 크게 잡힌
서브가 자기가 담당하는 모든 대역에서 앵커를 그냥 넘겨 버렸다 — 자신의 딥은
잉여 레벨 뒤에 숨고 크로스오버와 중역 사이 메인의 룸 홀만 온전히 과금되어,
앵커 항이 "가장 넓은 대역을 가장 큰 분기에 맡기는" 후보에게 몰래 보상을 주고
추천이 후보 목록의 상한을 따라갔다(같은 실측 세션에서 40–120이면 110,
40–100이면 100, 40–90이면 90). 매칭할 수 없는 경로(200–500 Hz 메인 커버리지
없음, `[x/2, x]` 빈 부족)는 경고와 함께 캡처 레벨을 유지한다 — 채점기 자체의
앵커 폴백과 같은 방식이다.

모든 후보가 같은 캡처에서 유도되므로, 실측 후보 envelope 목적함수 대신 게이트
스무딩 곡선 위의 후보별 이음새 목적함수를 쓴다.

```text
deficit_x,c(f) = max(0, max(smooth(max(|M'_x,c|, |U'_x|))(f), A_x,c) - smooth(|C_x,c|)(f))
```

첫 기준 항은 점별로 더 큰 분기를 max 이후에 스무딩한 것이다. 정렬된 합은 어느
빈에서도 더 큰 분기 아래로 내려가지 않으므로, 이 항은 두 분기가 실제로 겹치는
곳의 상쇄 간섭을 정확히 과금하며 어느 분기의 볼륨을 올려도 가려지지 않는다
(v2의 교차 후보 envelope는 서브가 메인보다 클 때 가장 넓은 대역을 서브에 맡기는
후보 — 목록의 최고 크로스오버 — 에 항상 승리를 넘겼고, 실측으로 확인됐다). 둘째
항 `A`는 후보 자신의 raw 200–500 Hz 중앙값으로, 합이 중역 아래로 내려간 이음새는
cut 전용 EQ가 합법적으로 채울 수 없는 구멍이다. 이 앵커 비교가 의미를 갖는 것은
서브가 배포 레벨(위의 `g_x` 트림)로 들어오기 때문이다. 앵커 위의 과잉은 의도적으로
과금하지 않는다(컷이 제거하고, 헤드룸은 내보내기에서 계산된다). 군지연 매끄러움은
계산·보고되지만 점수에 넣지 않는다.
LR 크로스오버 자체의 군지연 범프가 `1/fc`로 커져 ms 단위 매끄러움 항은 높은
크로스오버를 구조적으로 편애하고, 우연히 더 매끈한 오정렬 지연을 고를 수도
있기 때문이다. 점수는 가중 결손 RMS + 0.20 p95 + 0.05 최악에,
`0.02 dB/ms × |tau − tau_arrival|`(0이 아니라 측정된 도달 — 물리적으로 특권을
갖는 지연 — 을 향한 정규화)과 `0.1 dB/octave × log2(x / 40 Hz)`(문서화된
로컬라이제이션 동률 판정 — 실제 이음새 결함보다 한참 작아 동등한 이음새
사이에서만 결정)를 더한 것이다.

보고되는 배포 트림 `g_x` 외에는 어떤 후보도 레벨 정렬을 받지 않으며, 트림 자체를
점수를 좋게 만들려고 변주하는 일도 없다. 하나의 서브 전용
응답이 L과 R 양쪽에 재사용되므로, 대칭 베이스 매니지먼트 라우팅은 명시적 한계이다.
모든 캡처는 동일한 업로드 스윕 해시, 캘리브레이션, 마이크 장치/채널, 게인 상태, P0
측정 위치, 고정된 음향 마커 스피커를 사용해야 한다. 이 고정 마커는 상대적 복소 경로
비교만 승인한다. 전역 `timing_eligible=false` 상태를 바꾸지 않으며 L/R 스피커 지연
보정을 승인할 수 없다.

보고서는 항상 `needs_confirmation=true`로 설정한다. 1순위 설정은 복소 합 예측이며,
측정된 L+sub/R+sub 증거가 아니다. 사용자는 이를 하드웨어에 적용하고 다음 결합 P0
캡처를 수행해야 보정 워크플로가 계속된다.

### 광대역 1회 측정 크로스오버 합성

`phase3-wide-band-crossover-synthesis-v1`은 크로스오버당 3회가 아니라 총 3회의
캡처로 같은 최적화기를 구동한다. 서브는 베이스 매니지먼트 로우패스를 최대
`f_meas`로 돌린 상태(또는 진짜 우회 상태)에서 1회 측정하고, 메인 두 채널은 서브
출력을 꺼 스피커 하이패스가 해제된 상태에서 1회씩 측정한다. 각 후보 크로스오버
`x`에 대해 가상의 `SeparatedCrossoverPaths` 상태를 다음과 같이 합성한다.

```text
M'_x,c(f) = M_c(f) * HP_model(x, f)
U'_x(f)   = U_meas(f) * LP_model(x, f) / LP_model(f_meas, f)    (다이얼 f_meas)
U'_x(f)   = U_meas(f) * LP_model(x, f)                          (우회 선언 시)
```

나눗셈은 측정 상태의 필터를 두 번째 필터로 쌓는 대신 *치환*한다. LR4 250 Hz
로우패스는 저역에 약 1.8 ms의 군지연을 갖는데 실사용 상태에는 이 필터가 없으므로,
남겨 두면 지연 추천이 그만큼(80 Hz 크로스오버에서 52도) 편향된다. 같은 정렬에서
`x <= f_meas`이면 치환 비율은 모든 주파수에서 `|LP(x)/LP(f_meas)| <= 1`이라 측정
잡음이 증폭되지 않으며, 측정 다이얼을 넘는 후보는 거부된다. 선택 가능한 정렬
모델은 LR4(2차 버터워스 제곱, 크로스오버에서 두 분기 동상), LR2(1차 두 단
캐스케이드, 크로스오버에서 두 분기 역상), 2차 버터워스이고, THX식 베이스
매니지먼트가 12 dB/oct 새틀라이트 하이패스와 24 dB/oct 서브 로우패스를 짝짓기
때문에 분기별로 따로 선언한다.

이 방식은 실측 방식의 모델 무가정성을 스윕 3회 세션 및 최대 12개의 다이얼 가능한
후보 목록과 명시적으로 교환한다. 방·드라이버·배치는 공유 마커 타임라인 위의 측정
복소 데이터로 남고 베이스 매니지먼트 필터만 모델링된다. 모델 의존은 정직하게
표기되며 실제로 중요하다. 하드웨어의 실제 슬로프가 선언과 다르면 — 특히 12 vs
24 dB/oct는 크로스오버에서 분기 상대 위상을 뒤집는다 — 지연·극성 추천이 틀릴 수
있고, 보고서는 실측 방식의 "크로스오버 전달함수를 합성하지 않았다" 문구 대신 그
경고를 담는다. 마커 타임라인 대수는 상태 간 결합을 정확하게 유지한다. 각 캡처의
마커가 그 상태의 처리 지연을 흡수하므로, 두 하드웨어 상태에서 조립한 서브-메인
도달차는 실사용 상태의 값과 같다. 캡처 간 마커 레벨 게이트는 0.3 → 0.5 dB로
넓어진다. 광대역 다이얼의 하이패스가 서브 캡처에서만 기준 스피커의 ≥650 Hz 마커
대역을 최대 ~0.2 dB 감쇠시키기 때문이다. 추천은 예측 전용으로 유지되며, 이어지는
필수 결합 L+sub/R+sub 캡처가 선택된 크로스오버에서 하드웨어의 실제 필터를 처음
재는 측정이다.

### 분리된 메인/서브 일관성 진단

메인 전용, 서브 전용, 그리고 실제 결합 응답이 위상과 함께 존재하는 경우 복소 예측은
다음과 같다.

```text
M(f) = 10^(L_main(f)/20) exp(j phi_main(f))
U(f) = 10^(L_sub(f)/20)  exp(j phi_sub(f))
L_sum_pred(f) = 20 log10(max(|M(f) + U(f)|, 1e-15))
```

이 진단은 `[0.5 fc, 2 fc]` 구간에서 `L_sum_pred`와 측정된 결합 크기 사이의 로그 주파수
가중 RMSE를 보고한다. 상쇄 손실 `max(0, max(L_main,L_sub)-L_combined)`는 별도로
기록한다. 현재 CLI는 측정된 순위를 게시하기 전에 복소 합 RMSE가 1.0 dB 이하일 것을
요구한다. 이 진단들은 후보 점수에 더해지지 않는다. 저장된 서브 위상에 180도를 더하는
것은 반사실적 복소 합 검사일 뿐이다. 실제로 측정된 반전 결합 실행이 없다면 그
상쇄 손실 지표는 증거가 아니다.

## minimum-phase FIR

단측 컷 요청은 실수 우함수 로그 크기 스펙트럼으로 미러링된다. 역 FFT가 real-cepstrum을
형성한다. 시간 0 항과 나이퀴스트 항은 유지되고, 양의 케프렌시는 두 배가 되며, 음의
케프렌시는 0이 된다. 이어지는 FFT, 복소 지수화, 역 FFT가 인과적 minimum-phase FIR을
산출한다.

Phase 1에서는 암시된 FFT 길이의 전체 임펄스를 유지하여 검증되지 않은 절단 창을
피한다. 그 응답은 16배 조밀한 그리드에서 검사된다. 전부 컷인 설계는 `0.999999` 진폭의
단위 상한을 유지한다. 부스트를 포함하는 설계는 +3 dB 바로 아래에서 같은 비율을
사용한다. 보간이 해당 상한을 넘으면 필터 전체가 감쇠된다. 결코 상향되지 않는다.
정규화 dB는 `project.json`에 채널별로 보고된다. 네이티브 그리드 테스트는 실현된
크기가 요청 값에 보고된 정규화를 더한 값과 같은지 검증한다.

## Phase 4 측정 응답 리플레이

Phase 4의 입력은 측정된 48 kHz 크기 그리드와 최소 하나의 L/R 결합 측정 위치이다.
현재 fixture에서는 가중치 2의 중앙 P0이다. 응답 값은 절대 SPL과 REW 주파수 원점을
유지한다. 이 경로는 후보 레벨 정렬도, 타임라인 이동도 수행하지 않는다. 타깃은 기존
200-500 Hz 강건 기준 규칙으로 채널별로 독립 정렬된 다음, 위의 유계 게인 목적함수와
100-140 Hz 공통-채널별 스테레오 규칙이 적용된다.

크기 설계는 650 Hz까지의 측정 빈을 사용한다. 요청된 보정은 20 Hz부터 500 Hz까지
활성이고 500에서 650 Hz까지 raised-cosine으로 0 dB에 복귀한다. 네이티브 FIR 그리드로
리샘플링할 때 20 Hz 미만과 650 Hz 이상에는 명시적으로 0 dB를 기록한다. 기본 FIR은
48 kHz에서 `N=16384` 탭이므로 단측 설계 빈은 8,193개이다. FIR 실현은 응답이 측정
그리드로 되보간되기 전에 `16N` 응답 FFT에서 검사된다.

### 보수적 감쇠 한계 재설계

첫 설계 실행은 보존되며, 제약 없는 요청 `A_req`가 설정된 12 dB 한계를 초과했을 때의
`attenuation-limit-reached` 경고도 함께 보존된다. 이후 Phase 4는 버전 관리되는 11.5 dB
안전 목표를 사용하고, 스무딩된 요청과 스무딩되지 않은 요청 모두에 하나의 균일한
강도를 적용한다.

```text
s = min(1, 11.5 dB / A_req)
a_safe(f) = s a_initial(f)
```

이 재설계는 이미 허용된 보정을 1 쪽으로 축소할 뿐이다. 보호된 딥을 부스트로 바꾸거나
타깃 정렬을 변경할 수 없다. 결과로 나온 모든 요청이 유한하고, +3 dB 이내이며, 감쇠가
11.5 dB를 넘지 않을 때만 해소된다. 레거시 측정 fixture는 L/R에 대해 초기 요청
16.9146/16.9279 dB, 강도 0.679885/0.679353, 스무딩된 재설계 최댓값 8.1163/8.1065 dB를
기록했다. 타입 수준의 재설계 게이트가 해소되더라도 원래의 12 dB 경고는 계속 노출된다.

### 예측과 IR 진단

`H_c,real(f)`를 채널 `c`의 조밀 FFT로 실현된 FIR 크기라 하자. 응답 리플레이는 순수하게
주파수 영역 예측이다.

```text
L_c,pred(f) = L_c,measured(f) + H_c,real(f)
```

이는 20-500 Hz에서 정렬된 타깃과 대조 검사된다. 유지된 원시 결합 IR `x_c[n]`에 대해
별도의 진단은 유한 선형 컨볼루션을 계산한다.

```text
y_c[n] = x_c[n] * h_c[n]
t_start,y = t_start,x
```

인과적 FIR이 상대 시간 0에서 시작하기 때문이다. 따라서 원본 REW `startTime`이
보존된다. 입력도 결과도 피크 정렬되지 않는다. `max(abs(y_c))`는 룸 IR 진단일 뿐이다.
이는 FIR로 필터링된 재생 신호의 실제 피크가 아니며, 클리핑이나 권장 헤드룸을 결정할
수 없다.

### 오프라인 수치 게이트와 상태

일반적인 유한성/유계 게인/실현 응답 게이트에 더해, Phase 4는 다음을 요구한다.

- 설계 전에 네 개의 L/R x sub-A/B 분리 경로 예측 모두가 45-180 Hz 복소 합 크기 RMSE
  1.0 dB 이하일 것;
- 모든 보호된 딥 빈에서 실현 감쇠가 0.5 dB 이하일 것;
- 모든 보호된 딥 빈에서 실현 부스트가 0.05 dB 이하일 것;
- 타깃 RMSE가 개선되고, 광대역 피크 RMSE가 최소 10% 개선되며, 최악의 광대역 피크
  오차가 각 채널에서 최소 5% 개선될 것;
- 필요한 모든 안전 재설계가 NaN/Inf, +3 dB 초과 게인, 과도한 감쇠 없이 해소될 것.

이 게이트들을 통과하면 `numerical_prediction_passed=true`만 설정된다. 타입 수준 상태는
`predicted-only-measured`로 유지된다. 하드웨어 검증, 폐루프 통과, 최종 내보내기 자격,
권장 헤드룸은 추론될 수 없다.

### 실시간 어댑터, 폐루프 비교, 헤드룸

실시간 개발자 베타는 위의 목적함수를 다시 구현하지 않고 `run_phase4_offline`을
재사용한다. 동일 주파수 그리드에서 채택된 L/R 캡처 쌍이 측정된 측정 위치가 된다. P0는
기본적으로 가중치 2이다. P0_END가 존재하면 P0와 P0_END는 각각 가중치 1이다. P1-P8은
각각 가중치 1이다. 시험에는 최소한 채택된 P0 쌍이 필요하다. 두 중앙 쌍이 모두
존재하면, `m_c,p`를 200-500 Hz 구간의 중앙 레벨이라 하고 각 채널 응답에서 이를
제거한다. 시험 설계는 추가로 양쪽 채널에 대해 다음을 요구한다.

```text
|m_c,P0_END - m_c,P0| <= 1.0 dB
RMSE_20-500((L_c,P0_END - m_c,P0_END) - (L_c,P0 - m_c,P0)) <= 6.0 dB
```

절대 레벨 한계는 세션/게인 안정성 검사로 남는다. 형태 한계는 P0_END가 P1-P8 이후
수동으로 복귀해 측정되기 때문에 의도적으로 느슨하다. 이는 심각한 경로/위치 변경만
기각하며, 정확한 모달 재현을 요구하지 않는다. 이 검사는 반복 레벨과 대략적인 형태를
확인하는 것이지 도착 시간 재현성을 확인하는 것이 아니다. 실시간 Phase 4 시험은 기존
네이티브 48 kHz 길이인 16,320 샘플을 사용한다. 오프라인 Phase 4 기본값은 16,384로
유지된다.

시험 WAV/ZIP은 여전히 예측 전용이다. 사용자가 Roon에서 바로 그 필터를 수동으로
활성화하고 백엔드 타임스탬프가 찍힌 사용자 확인 진술을 기록한 뒤, 새로 채택된 검증
P0 L/R 캡처를 기존 `validate_frequency_prediction` 게이트로 해당 기준선 P0 응답과
비교한다. 이 확인 진술은 Roon을 검사하거나 제어하지 않는다. 양쪽 채널 모두 통과해야
하며 어떤 검증 문제도 남아 있어서는 안 된다. v2 일치도 점수는 먼저 부호 있는 잔차를
형성하고, 광대역 피크 채점에 사용되는 것과 동일한 1/12 옥타브 가우시안 로그 주파수
스무딩을 적용한다.

```text
r_c(f) = smooth_1/12oct(L_verified,c(f) - L_pred,c(f))
E_pv,c = sqrt(mean_20-650Hz(r_c(f)^2)) <= 3.0 dB
```

스무딩되지 않은 RMSE는 진단용으로 유지된다. 적합된 광대역 레벨 오프셋은 제거되지
않으며, 위의 독립적인 타깃 개선 게이트는 여전히 필수이다. 이것이
`live-closed-loop-validation-v4`이다. 이는 minimum-phase 크기 보정을 검증할 뿐, L/R
도착이나 앱이 제어하는 Roon 전송 상태를 검증하지 않는다.

그 게이트 이후, 기존 Phase 6 엔진이 동일한 물리적 게인 의도를 여섯 개 네이티브 레이트
전부에서 실현한다. 내보내기 전에 `verified-trial-native48-response-binding-v1`이 확인
진술 이후의 검증 증거와 연결된 바로 그 시험 `h_trial,c`를 최종 네이티브 48 kHz 멤버
`h_final,c`와 비교한다.

```text
max_20-20000 |M_trial,c(f) - M_final,c(f)| <= 0.05 dB
max_20-650 |GDrel_trial,c(f) - GDrel_final,c(f)| <= 0.02 ms
```

등록된 좌/우 측정 레퍼런스 `r_c`와 네이티브 FIR `h_c`에 대해
`validation-signal-and-response-peak-v3`은 다음을 계산한다.

```text
P_in,c  = true_peak_4x(r_c)
P_out,c = true_peak_4x(r_c * h_c)
G_peak  = max_c 20 log10(P_out,c / P_in,c)
G_fir   = max_c 20 log10(sum_n |h_c[n]|)
headroom_db = ceil_0.1(max(0, G_peak, G_fir) + 1.0 dB)
```

트루 피크 추정은 4배 시간 해상도의 FFT 제로 패딩을 사용한다. FIR L1 노름은 샘플
피크가 1 이하인 임의의 입력에 대해 출력 샘플 피크를 한정하지만, 일반적인 음악보다
훨씬 보수적일 수 있다. 그 결과는 시작 감쇠값이며, 아날로그 재생 체인에 대한 증명이
아니다. 엄격한 익스포터는 최종 프로젝트가 경로와 SHA-256을 저장하기 전에 여섯 레이트
ZIP을 기록하고 되읽는다. 직렬화 필드 `measuredTruePeakRatioDb`는 호환성을 위해
유지된다. 이 필드는 등록된 디지털 스윕 비율을 담고 있으며, 음향적으로 측정된 트루
피크가 아니다.

## 예측 검증 지표

Phase 1 합성 경로에서는 모든 측정 위치와 채널이 자신의 원시 합성 IR과 컨볼루션되어
동일한 그리드에서 분석된다. Phase 4에서는 예측이 대신 위에 명시된 대로 실현된 FIR
크기를 권위 있는 저장 REW 크기에 더한다. 두 경로 모두 원시 및 예측 20-500 Hz 타깃
RMSE를 계산한다. 모달 피크 채점은 먼저 잔차를 1/12 옥타브 가우시안으로 스무딩한 뒤
원시 양의 오차가 1 dB 이상인 빈을 평가한다. 그 RMSE와 최악 오차가 모두 개선되어야
한다. 유효하지 않은 임계값, 유한하지 않은 중간 값, 양의 실현 게인, 과도한 실현
감쇠는 fail-closed로 처리된다.

채널 순서는 스테레오 WAV 인터리브/되읽기 테스트와 매니페스트 메타데이터로 구조적으로
검증된다. 음향적 채널 스왑 검출에는 태깅된 실제 재생이 필요하며, 이는 장래의 폐루프
게이트이지 Phase 4 오프라인 예측기의 주장이 아니다.

합성 예측도, 측정 기준선 응답 리플레이도 실제 룸 검증이 아니다. UI와 상태 보고서는
어느 출력도 "보정 완료"로 표시해서는 안 된다.

## Phase 6 네이티브 샘플레이트 재설계

Phase 6은 Phase 4가 산출한 측정 주파수 기반의 유계 L/R 게인 의도에서 시작한다. 48 kHz
임펄스를 결코 리샘플링하지 않는다. 레이트 `F_s`에 대해 네이티브 FIR 길이는 하나의 공통
유리수 지속 시간을 갖도록 선택된다.

```text
T = 17 / 50 s = 0.34 s
N(F_s) = F_s T
Delta_f = F_s / N(F_s) = 50 / 17 Hz
```

필요한 모든 레이트에서 `N`은 짝수 정수가 된다.

| Sample rate | Native samples |
| ---: | ---: |
| 44,100 Hz | 14,994 |
| 48,000 Hz | 16,320 |
| 88,200 Hz | 29,988 |
| 96,000 Hz | 32,640 |
| 176,400 Hz | 59,976 |
| 192,000 Hz | 65,280 |

공유된 물리적 빈 간격은 20 Hz의 단위-보정 경계가 44.1 kHz 계열과 48 kHz 계열에서
서로 다른 주파수에 놓이는 것을 방지한다. 각 레이트는 여전히 자신의 네이티브 나이퀴스트
범위를 갖는다. 650 Hz 이상의 빈은 48 kHz 나이퀴스트 범위로 불필요하게 제한되지 않고
단위로 유지된다. 단측 의도는 Phase 4에서 사용된 것과 동일한 real-cepstrum 스펙트럼
인수분해로 인과적 minimum-phase FIR로 변환된다. FFT 구현은 이러한 2의 거듭제곱이 아닌
짝수 크기를 허용한다.

조밀한 삼각 보간은 설계 빈 사이에서 단위를 아주 조금 넘는 피크를 만들 수 있다.
`s_c,r <= 0`을 채널 `c`와 레이트 `r`에 대해 찾아낸 감쇠 전용 안전 정규화라 하자.
Phase 6은 하나의 공통 값

```text
s_common = min_(c,r) s_c,r
```

을 사용하고 각 FIR에 `s_common - s_c,r <= 0`을 추가 감쇠로 적용한다. 이는 부스트를
생성하거나 증가시킬 수 없고, +3 dB 상한을 보존하며, 레이트 간 비교 전에 채널/레이트
의존적인 광대역 오프셋을 제거한다.

로그 간격 질의 집합 `Q`에 대해, 각 레이트에서 실현된 응답을 48 kHz 레퍼런스와
비교한다.

```text
Delta_M,c,r = max_(f in Q_M) |M_c,r(f) - M_c,48(f)|
Delta_GD,c,r = max_(f in Q_GD) |GD_c,r(f) - GD_c,48(f)|
```

`Q_M`은 20 Hz–20 kHz를, `Q_GD`는 20–650 Hz를 포괄한다. 제품 한계는 각각 0.05 dB와
0.02 ms이며, 호출자는 이를 더 엄격하게만 할 수 있다. 소스 출처는 별도로 검사된다.
Phase 4 CSV를 먼저 원래의 48 kHz/16,384 그리드에서 재합성하며, 해시로 연결된 모든
float32 시험 탭을 `1e-6` 이내로 재현해야 한다. 이어서 동일한 허용 의도가 여섯 개의
새 네이티브 그리드로 들어간다. 따라서 새 그리드가 레거시 그리드와 같은 샘플 수열을
갖도록 잘못 요구되지 않는다.

이것들은 수치적 샘플레이트 일관성 게이트이며, 하드웨어 검증이 아니다. 오프라인
Phase 6 명령은 재생 트루 피크, 권장 헤드룸, `export_eligible`을 계산하지 않는다.
동일한 네이티브 레이트 엔진과 익스포터를 호출하기 전에 이미 통과한 폐루프 증거와
신호/FIR 한계 헤드룸을 추가할 수 있는 것은 별도의 실시간 어댑터뿐이다.

원작자가 MIT 라이선스로 허락하여 이식했다.

이 절은 코드가 아니라 **신호가 어떤 순서로 무엇을 겪는지**를 적는다. 어디까지가
원작 설계이고 어디부터가 이 프로젝트의 추가인지도 함께 표시한다.

### 들어가는 것

중앙 청취석(P0)의 좌/우 임펄스 응답 한 쌍. 48 kHz, 32,768 샘플(0.68 s).
기존 Phase 4 경로가 여러 좌석의 **크기만** 쓰는 것과 달리, SECS는 한 지점의
**복소 응답(크기 + 위상)** 을 전부 쓴다. 그래서 시간축까지 손댈 수 있고, 동시에
그 한 좌석에 과적합될 위험도 함께 진다.

### 1단계 — 응답을 크기와 시간으로 분해한다 (원작)

방의 전달함수는 "최소위상 성분 × 올패스 성분"으로 유일하게 분해된다.

- **최소위상 성분** — 크기 곡선이 결정하는 부분. EQ로 고칠 수 있다.
- **올패스(초과위상) 성분** — 크기는 1인데 주파수마다 도착 시간이 다른 부분.
  EQ로는 원리상 고칠 수 없고 올패스 필터로만 상쇄된다.

SECS는 켑스트럼(로그 크기의 역변환)으로 이 분해를 한다. 측정 임펄스의 피크를
기준으로 정렬한 뒤 최소위상 재구성으로 나누면 남는 것이 순수한 초과위상이다.

이 분해가 SECS와 일반 룸 EQ의 결정적 차이다. PEQ나 최소위상 FIR은 크기만 고치므로,
같은 크기 곡선을 만들어도 저역의 도착 시간 흐트러짐은 그대로 남는다.

### 2단계 — 크기 쪽 (원작)

**(a) 5밴드 분수 옥타브 스무딩.** 응답을 LR4로 다섯 대역으로 나눠 각 대역을 서로
다른 분해능으로 스무딩한 뒤 다시 합친다. 기본값(Normal)은 1/24 → 1/12 → 1/6 →
1/3 → 1/1 옥타브로, 저역일수록 세밀하고 고역일수록 뭉툭하다. 이유는 물리다.
저역 모드는 실재하고 반복 가능하지만, 고역의 촘촘한 요철은 마이크를 몇 cm만 옮겨도
바뀌는 간섭 무늬라 쫓아갈 대상이 아니다.

**(b) 적응 타깃.** 고정 커브를 쓰지 않는다.

- 스피커와 방이 실제로 내는 자연 저역/고역 컷오프를 찾아, 그 바깥은 억지로 올리지
  않고 자연 롤오프를 따라간다.
- 기준 레벨을 100 Hz–10 kHz 크기의 **35퍼센타일**로 잡는다. 평균(50)이 아니라
  아래쪽에 정박하는 이유는 "딥을 부스트로 채우기보다 피크를 깎아 맞춘다"는 보수적
  선택이다. 대가로 응답의 약 65 %가 타깃 위에 놓여 컷 대상이 되고, 보정 후 전체
  레벨이 내려간다.
- 여기에 베이스 셸프와 틸트를 곱한다.

**(c) 크기 역보정.** 스무딩된 크기를 타깃으로 나눈 역수를 만든다. **컷은 깊이 제한이
없고 부스트만 상한**(기본 +6 dB)이 걸린다. 같은 철학의 연장이다.

**(d) 매크로 EQ.** 그 필터를 걸었다고 가정한 결과를 1옥타브로 스무딩해 타깃과
비교하고, 남은 광대역 오차를 ±6 dB 안에서 다시 보정한다. 음색의 큰 흐름을 맞춘다.

**(e) 피크 크러시 — 500 Hz 아래만.** 그래도 타깃 위로 솟아 있는 잔여 피크를 한 번 더
누른다. 강도는 해상도 설정에 따라 0.3 / 0.6 / 1.0. 300 Hz까지 전량 적용되고
300 → 500 Hz에서 0으로 사라진다. "피크는 링잉하므로 딥보다 나쁘다"는 판단이 코드로
표현된 자리다.

**(f) 커튼 — 기본 300 Hz.** 커튼 위로는 협대역 정밀 보정을 서서히 끄고 1옥타브급
광대역 음색 보정만 남긴다. 커튼에서 2×커튼까지 선형으로 페이드한다.

### 3단계 — 시간 쪽 (원작)

초과위상 성분의 켤레를 취하면 방이 만든 위상 왜곡을 상쇄하는 올패스가 된다. 문제는
이 올패스가 **원인보다 먼저 소리를 낸다**는 점(프리링잉)이다. 그래서 대역별로 예산을
다르게 준다.

| 대역 | 허용 프리링잉 |
| --- | --- |
| 저역 | 목표 지연까지 (기본 10 ms) |
| 중역 | 그 절반 (≤5 ms) |
| 고역 | 그 1/4 (≤2.5 ms) |

저역은 파장이 길어 프리링잉이 잘 들리지 않는 반면 위상 오차의 대가는 크고, 고역은
정반대다. 대역별로 창을 씌운 뒤 LR4 가중으로 합치고, 크기를 1로 정규화해 올패스를
유지한다.

**위상 신뢰도 가드.** 응답이 깊은 널에 빠진 주파수에서는 측정된 위상 자체를 믿을 수
없다. SECS는 그런 지점에서 위상 보정을 무보정(1) 쪽으로 되돌린다. 기준은 자기 크기가
대역 평균 대비 약 −15 dB 아래로 내려가는 구간이다.

**실현 가능성 가드(`phase-guard-v1`, 이 프로젝트 추가 — "개량 SECS" 옵션, 기본
켜짐).** 위의 창 적용에는 원작이 검사하지 않는 실패 모드가 있다. 방의 저음이
프리링잉 예산으로 당길 수 있는 것보다 *늦게* 도착하면(흔하다 — 실제 시스템에서 서브
경로의 DSP 지연 + 모드 저장이 38–57 ms였고 예산은 10 ms), 잘린 뒤 재정규화된
올패스는 "보정 축소"로 퇴화하지 않는다. 군지연의 부호가 뒤집혀 의도했던 앞당김이
추가 지연이 된다(2026-08-03 실제 필터가 20–120 Hz를 70–200 ms — 7~16 주기 —
지연시켰는데, 올패스는 어디서도 크기를 바꾸지 않으므로 모든 크기 지표는
정상이었다). 가드가 켜지면 창이 적용된 보정기를 주파수 빈마다 무보정과 비교한다.
잔여는 `excess × corrector` 대 `excess` 단독이며, 보정기가 잔여 군지연을 5 ms
이상 악화시키는 곳은 1로 되돌린다(판정은 1/3 옥타브로 스무딩하고 결과를 단위
크기로 재정규화해 매끈한 올패스를 유지). 이어지는 2단계가 게이트 밴드마다
중앙값으로 결과를 검증해, 잔여 중앙값을 여전히 악화시키거나 보정기 홀로 그
밴드 게이트 한계의 60% 이상을 군지연으로 소모하는 밴드는 보정을 통째로
제거한다(반 옥타브 크로스페이드). 2.1 프로젝트에서는 밴드 단위 판정을 채널 간에 일치시킨다. 베이스 매니지먼트
크로스오버 아래는 서브 하나가 두 채널을 재생하므로, 한쪽 채널에서 보정을
제거했다면 두 채널 모두 제거한 상태로 다시 설계한다. 서로 다르게 두면 앰프가
합산하는 바로 그 대역에서 두 필터의 위상이 갈라진다 — 2026-08-04 실제 필터가
그렇게 20–30 Hz에서 L/R 84° 차이와 모노 저음 −1.95 dB를 남겼고, 채널별 검증
스윕은 한 번에 한 채널만 울리므로 이를 관측할 수 없다. 두 단계가 모두 필요한 이유: 실제 모드
구조에서는 기준 잔여의 빈별 군지연이 허용치를 아득히 넘는 잡음이라 빈별
비교가 분산 경쟁으로 퇴화하고, 실측에서 일관된 +34 ms 편향을 실은 보정기가
그 판정을 통과했으며 비가중 잔여 통계는 오히려 "개선"으로 보이기까지 했다.
끄면 원본 알고리즘이 비트 단위 그대로 실행되며, SECS.py 패리티 fixture가
이를 고정한다.

**확장 지연 상한(이 프로젝트 추가, 음악 전용, 기본 설정은 자동).** 지연의
대가는 립싱크뿐이고 음악 재생에는 없다. 그래서 상한(UI에서 자동 또는
10/30/60/100 ms)을 올릴 수 있으며, 올리면 그 값이 곧 목표 지연으로 쓰인다(2–10 ms
자동 탐색은 크기만 보므로 사용자가 의도한 위상 이득을 볼 수 없다). 예산이 실제로 쓰이게
하는 장치 셋이 있고, 모두 개량 경로+확장 상한에서만 작동한다: (1) 저역 벌크
앞당김을 먼저 추정해(20–90 Hz 복소 상관, 0.5 ms 스텝) 대역 스무딩 앞뒤로
벗겨냈다가 되입힌다 — 스무딩은 ≤10 ms의 완만한 램프용 설계라, 50 ms 램프가
창 하나 안에서 만드는 여러 바퀴 회전을 평균하면 그냥 상쇄된다(실측: 이 분리
전에는 60 ms 예산에서도 +26~+41 ms *지연하는* 보정기가 나왔다); (2) 저역
프리링잉 창을 평탄상부+10 ms 테이퍼로 바꾼다 — 원본의 전구간 코사인 테이퍼는
복원된 51 ms 앞당김을 5.6% 이득 지점에 놓아 지워버렸다; (3) 가드와 게이트가
의도된 앞당김을 비대칭으로 허용한다(예산+한계까지; 추가 지연은 종전 한계
그대로). 중·고역 프리링잉 상한 10/5 ms는 전 과정에서 유지된다. 2026-08-03
실측 캡처 기준(60 ms 상한, 청취점 1–4 kHz 기준 대역 도달): L 20–40 Hz
+37.8→+8.5 ms, L 40–70 Hz +55.6→+4.3 ms, R 40–70 Hz +57.1→+1.4 ms. R 20–40 Hz는
−18.5 ms로 과보정이 남는다(|오차|는 절반; 채널당 벌크 추정이 한 값이라 이웃
대역과 지연이 달랐던 탓). 공유 서브 대역 L/R 정합은 유지된다(최악 3°, 모노
합산 손실 0.00 dB).

**상한 자동 결정(기본값).** 최적 상한은 "클수록 좋다"가 아니라 "방이 필요로
하는 만큼보다 조금 큰 값"이다: 같은 캡처로 60 vs 100 ms를 통제 비교하면 추가
40 ms가 대역 도달 차이는 몇 ms밖에 못 바꾸면서 필터의 초기 에너지 번짐을
깊게 하고(40–70 Hz 내용물이 피크보다 49→64 ms 앞에서 시작, 70–120 Hz는
18→31 ms) 재생 지연만 40 ms 더한다. 그래서 기본값에서는 설계가 필요량을 직접
잰다: 설계가 보정할 바로 그 초과위상 역수에 대해 20–90 Hz 정합필터 벌크 앞당김
스캔을 채널별로 250 ms 하드 상한까지 돌리고, 두 채널 중 큰 필요량 + 평탄창
테이퍼 10 ms(앞당겨진 내용물이 테이퍼에 걸리지 않게)로 상한을 정한 뒤 5 ms
격자로 올림한다. 원본 10 ms 예산이면 충분한 쌍은 정확히 그 예산으로 남아 확장
지연을 전혀 쓰지 않는다. 결정된 상한과 측정 필요량은 설계 요약에 기록되고,
내보내기 경로는 재프로브 없이 기록값을 그대로 재사용한다. 수동 상한도 계속
가능하며, 개량 경로 없이 확장 상한을 쓰는 조합은 검증이 거부한다(원본
알고리즘에 확장 고정 지연을 주면 실측된 스무딩 상쇄 실패가 재현되기 때문).
2026-08-03 캡처에서 프로브는 L 51.0 / R 56.0 ms를 읽어 70 ms로 결정하고, 70 ms
설계는 게이트를 통과하며 청취점에서 L 20–40 Hz +12.8, L 40–70 Hz +1.6, R
40–70 Hz +0.2 ms — 사용자가 아무것도 고르지 않아도 손으로 고른 최적 상한과
동급이다.

**대역별 τ 분해: 조사 후 기각(2026-08-04).** 남은 20–40 Hz 잔차는 당연한
개선안을 부른다 — 채널당 스칼라 하나 대신 대역별 앞당김 프로파일로 회전하기.
방의 에너지 중앙값 지연이 20–40 Hz ~42 ms vs 40–70 Hz ~57 ms로 실제 기울기가
있기 때문이다. 구현해 실측 캡처로 재보니 모든 변형이 스칼라에 졌다: 각 옥타브
대역의 정합필터 판독을 그대로 쓰면 쓰레기 대역 하나가 설계를 오염시킨다
(18–35 Hz 초과위상은 coherence 0.17–0.22로 잡음 바닥 0.21 수준 — 그 대역엔
단일 도달 자체가 없다 — 그런데 그 "207 ms" 판독이 자동 상한을 220 ms로 몰고
가 게이트 +39 ms 위반과 모노 74° 분열을 만들었다); coherence만큼 광대역
앵커로 블렌딩하면 회전 몇 ms 변화가 위상 가드의 아슬아슬한 대역 판정을
뒤집어 L 20–40 Hz가 +12.8→+34.5 ms로 퇴행했고; 0으로 블렌딩하면 한 채널
프로파일이 무너져 L/R 판정이 갈라지고 2.1 정합이 공유 대역을 양채널 모두
제거해 보정이 아예 사라졌다. 회전은 스칼라로 유지한다. 조사에서 남긴 것은
진단 API(`secs_low_band_advance_profile_ms`)다: 대역별 정합필터 판독을
coherence, 잡음 바닥, 0–1 신뢰 가중치와 함께 보고해 쓰레기 판독을 쓰레기로
알아볼 수 있다. 잔차 자체의 맥락: R 20–40 Hz의 −18 ms 피크 판독은 상당 부분
엔벨로프 로브 인공물로, 강건한 에너지 중앙값 잔차는 R −8.3 ms / L +19.5 ms이며
저역 가청 임계로 흔히 인용되는 20–40 ms 대비 여유가 있다.

**군지연 게이트(이 프로젝트 추가, 설계 시점 판정).** 올패스 결함은 어떤 크기
지표에도 보이지 않으므로 설계된 48 kHz 탭 자체를 잰다. 래핑된 위상 유한차분으로
빈별 군지연을 구하고, 크기 가중 밴드 중앙값을 필터 자신의 1–16 kHz 기준선에
상대화하며, L/R 중 나쁜 쪽을 쓴다. 한계: 20–100 Hz 30 ms, 100–300 Hz 15 ms,
300–1000 Hz 8 ms — 공표된 가청 임계의 형태(중역 수 ms, 저역 20–40 ms 인용)에
여유를 더한 값이다. 개량 옵션에서는 하드 게이트(설계 실패)이고, 원본
알고리즘에서는 경고만 하므로 보존된 원본을 비교용으로 계속 쓸 수 있다. 리포트는
어느 쪽이든 설계 요약에 실린다.

**목표 지연 자동 탐색.** 필터 전체를 몇 ms 뒤로 미룰지를 2–10 ms에서 1 ms 간격으로
탐색하고, L+R 합의 저역 가중 오차가 가장 작은 값을 고른다. 이 지연이 곧 위상 보정에
쓸 수 있는 프리링잉 예산이므로, 길수록 저역 위상을 더 고칠 수 있고 레이턴시는 늘어난다.

### 4단계 — 스테레오 결합 (원작)

1. 피크 ±5 ms 구간의 RMS로 좌우 레벨을 맞춘다.
2. 두 채널 임펄스의 피크를 같은 샘플에 정렬한다.
3. 20 Hz–1 kHz 스무딩 응답의 L−R 중앙값 차이를 우 채널에 트림한다(±6 dB 한계).
4. 마지막 5 ms에 제곱 페이드를 걸어 꼬리를 끊는다.
5. 두 채널의 스펙트럼 최대치가 0 dB가 되도록 정규화한다. 이때 깎인 양이 내장
   프리앰프이고, 그래서 별도의 컨볼루션 프리앰프가 필요 없다.

### 5단계 — 2.0과 2.1이 갈리는 곳 (이 프로젝트 추가)

**2.0에서는** 위 모든 과정이 좌/우 완전히 독립이다. 좌우 스피커는 물리적으로 다른
소스이고 청취석까지 각자 다른 경로를 거치므로, 각자의 측정에 각자 대응하는 것이 맞다.

**2.1에서는** 베이스 매니지먼트 크로스오버 아래에서 **서브우퍼 하나가 두 채널을 모두
재생한다.** 이 대역에서 L 측정과 R 측정의 차이는 채널 차이가 아니라 같은 경로를 두 번
잰 측정 오차다. 원작 그대로 두면 SECS는 그 차이를 진짜로 믿고 좌우에 서로 다른 보정을
깊이 판다.

실제로 이 개발 환경(크로스오버 90 Hz)의 첫 2.1 필터를 분석한 결과다.

| 20–90 Hz 구간 | 공통화 없음 | 공통화 적용 |
| --- | ---: | ---: |
| L/R 크기 차이 (최대) | 11.1 dB | 0.8 dB |
| L/R 위상차 (최대) | 178.7° | 13.2° |
| L/R 위상차 (RMS) | 40.2° | 5.1° |

37 Hz에서 좌우가 11.8 dB 다르게 보정되고 있었고, 위상은 사실상 **역상**이었다.

크기보다 위상 쪽이 더 위험하다. 베이스 매니지먼트는 L+R을 **합해서** 서브로 보내므로,
두 채널 필터의 위상이 갈리면 모노 성분(대부분의 음악 저역)이 서브 입력에서 부분
상쇄된다. 게다가 검증 스윕은 한 번에 한 채널만 재생하므로 이 상쇄를 **원리적으로 볼 수
없다** — 측정으로는 멀쩡한데 음악에서만 저역이 빠진다.

그래서 2.1에서는 확정된 크로스오버 아래에서 크기와 초과위상 보정을 **양 채널 공통**으로
만든다.

- **크기**: 좌우 크기의 에너지 평균을 두 채널의 공통 입력으로 쓴다.
- **위상**: 두 채널의 초과위상 보정을 정규화 복소 평균으로 섞는다(올패스 유지).
- **가중치**: 크로스오버까지 100 %, 그 위 반옥타브에 걸쳐 0으로 페이드한다. LR4 기준
  반옥타브 위면 서브가 이미 12 dB쯤 내려가 메인이 주도하기 때문이다.
- **위상 신뢰도 가드는 여전히 각 채널 자기 크기를 본다.** 평균된 크기에는 그 채널의
  널이 지워져 있어, 평균을 보게 하면 가드가 풀려 버린다.

크로스오버 위(이 환경에서 127 Hz 이상)의 좌우 차이는 손대지 않는다. 그 대역은 좌우
메인이 각자 내는 소리라 진짜 채널 차이다. 실제로 110–180 Hz의 좌우 차이는 공통화
전후로 8.0 → 8.3 dB로 변하지 않았다.

2.0 프로젝트이거나 서브우퍼 설정이 하드웨어에서 확정되지 않았으면 이 단계는 통째로
비활성이며, 그때의 설계는 원작과 동일한 경로를 탄다.

### 이 프로젝트가 추가한 것 (원작 설계가 아님)

| 추가 | 하는 일 |
| --- | --- |
| 다지점 크기 평균 | 크기 쪽 입력을 측정한 모든 좌석의 좌석 가중 에너지 평균으로 교체. 위상은 P0 유지 |
| 타깃 커브 추종 | 앱에서 고른 하우스 커브를 500 Hz 0 dB로 재정박해 적응 타깃에 곱함 |
| 2.1 공유 서브 대역 공통화 | 위 5단계 |
| 폐루프 검증 | 필터를 실제로 걸고 다시 측정해 예측과 대조 (20–650 Hz 판정) |
| 레이트별 재설계 | 6개 Roon 네이티브 레이트마다 리샘플 후 재설계, 48 kHz는 검증본과 바이트 동일 |
| 헤드룸 산정 | 프로그램 소재의 시간축 피크 성장을 실측해 권장값 산출 |

이 추가분의 결함은 이 프로젝트 책임이며 원작자의 설계가 아니다.

### 설정값이 실제로 바꾸는 것

| 설정 | 무엇이 달라지나 |
| --- | --- |
| 부스트 상한 (기본 +6 dB) | 딥을 채우는 한계. 올리면 딥이 메워지지만 앰프·드라이버 부담이 늘어난다 |
| 틸트 | 옥타브당 기울기를 타깃에 더한다 |
| 베이스 셸프 / 코너 | 저역 목표를 올린다. 보정 후 저역이 얇게 느껴지면 여기부터 |
| 해상도 (Low/Normal/High) | 스무딩 분해능과 피크 크러시 강도를 동시에 바꾼다 |
| 커튼 (기본 300 Hz) | 협대역 정밀 보정의 상한 |
| 레이턴시 모드 | 일반 = 혼합위상, 저지연·무지연 = 최소위상만(위상 보정 포기) |
| 목표 지연 | 위상 보정에 쓸 프리링잉 예산 |

### 알려진 특성

- 컷이 깊이 무제한이고 500 Hz 아래에 피크 크러시가 겹치므로, **가장 큰 모드 봉우리
  주변에는 타깃보다 몇 dB 낮은 골이 남는다.** 실측 예: 15 dB짜리 41 Hz 모드를 제거한
  뒤 37–38 Hz에 −5.6 dB, 150–250 Hz에 평균 −1.7 dB. 보정 폭이 방의 구조보다 넓어
  봉우리 옆 골짜기까지 함께 깎이기 때문이다.
- 35퍼센타일 앵커와 피크 0 dB 정규화가 겹쳐 **보정 후 전체 음압이 내려간다.** 디지털
  레벨 이동일 뿐이므로 볼륨으로 보상하면 되지만, 검증 측정 시에는 볼륨을 반드시
  고정해야 한다.
- 혼합위상 필터는 응답 최대 이득이 0 dB여도 **광대역 프로그램의 시간축 피크를 수 dB
  키운다.** 실측에서 +2.8~+6.4 dB였고, 그래서 권장 헤드룸이 스윕 기준보다 훨씬 크다.
